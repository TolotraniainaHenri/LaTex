	Ce livre propose une analyse statistique des habitudes de vie à travers l'\textbf{Analyse en Composantes Principales (ACP)}. 
	
	L'étude porte sur \textbf{15 individus} et \textbf{11 variables} : sommeil, écran, sport, eau, travail, stress, alimentation, café, humeur, social et qualité du sommeil.
	
	\vspace{0.3cm}

	\begin{itemize}
		\item Visualiser les relations entre les habitudes.
		\item Identifier les profils types d'individus.
		\item Comprendre les facteurs clés du bien-être.
	\end{itemize}
	
	\vspace{0.3cm}
	
	Ce document s'adresse aux étudiants et professionnels souhaitant découvrir l'ACP à travers un cas pratique.

	\section{L'Analyse en Composantes Principales (ACP)}
	
	L'\textbf{Analyse en Composantes Principales} est une méthode statistique multidimensionnelle qui permet de :
	
	\begin{itemize}
		\item \textbf{Réduire} la dimensionnalité des données.
		\item \textbf{Visualiser} les relations entre variables.
		\item \textbf{Identifier} les structures sous-jacentes.
	\end{itemize}
	
	\subsection{Principe de l'ACP}
	
	L'ACP transforme les variables initiales (corrélées entre elles) en de nouvelles variables non corrélées appelées \textbf{composantes principales}. Ces composantes sont classées par ordre d'importance décroissante.
	
	\vspace{0.5cm}
	
	\begin{center}
		\fbox{
			\begin{minipage}{0.8\textwidth}
				\textbf{Formule mathématique :}
				
				\[
				\begin{cases}
					C_1 = a_{11}X_1 + a_{12}X_2 + \dots + a_{1p}X_p \\
					C_2 = a_{21}X_1 + a_{22}X_2 + \dots + a_{2p}X_p \\
					\vdots \\
					C_p = a_{p1}X_1 + a_{p2}X_2 + \dots + a_{pp}X_p
				\end{cases}
				\]
				
				Où les $C_i$ sont les composantes principales et les $a_{ij}$ sont les coefficients (poids) calculés à partir des données.
			\end{minipage}
		}
	\end{center}
	
	\subsection{Étapes de l'ACP}
	
	Le processus d'analyse se déroule en plusieurs étapes :
	
	\begin{enumerate}
		\item \textbf{Standardisation} des données pour éviter l'influence des unités.
		\item \textbf{Calcul de la matrice de corrélation}.
		\item \textbf{Extraction des valeurs propres et des vecteurs propres}.
		\item \textbf{Calcul des composantes principales}.
		\item \textbf{Interprétation des résultats}.
	\end{enumerate}

	\section{Présentation du graphique}
	
	Les valeurs propres indiquent \textbf{l'importance de chaque axe} (dimension) dans l'analyse.
	
	\begin{figure}[H]
		\centering
		\includegraphics[width=0.8\textwidth]{./img/valeurs_propres.png}
		\caption{Valeurs propres - Pourcentage de variance expliquée}
		\label{fig:vp}

	\section{Définition des valeurs propres}
	
	Les \textbf{valeurs propres} (ou "eigenvalues") sont des nombres qui mesurent l'importance de chaque axe.
	
	\begin{itemize}
		\item \textbf{Plus la valeur propre est grande} = Plus l'axe est important.
		\item La somme de toutes les valeurs propres = 100\% de l'information.
	\end{itemize}
	
	\begin{center}
		\fbox{
			\begin{minipage}{0.8\textwidth}
				\centering
				\textbf{Formule :}
				\[
				\lambda_i = \text{Variance expliquée par la dimension } i
				\]
				\[
				\text{Pourcentage expliqué} = \frac{\lambda_i}{\sum \lambda_j} \times 100
				\]
			\end{minipage}
		}
	\end{center}
	
	\section{Résultats de l'analyse}

		\item \textbf{Dimension 1} (52\%)
		\begin{itemize}

			\item Il oppose les deux styles de vie : "bien-être" vs "stress/sédentarité".
			\item C'est l'axe horizontal de tous nos graphiques.

	\section{Utilité des valeurs propres}
	
	\subsection{1. Évaluer la qualité de l'analyse}
	
	\begin{center}

	\end{itemize}
